# أدوات ومراجع غير مشحونة (Not bundled)

هذا المجلد **خارج** `assets/` عمداً، أي أنه **لا يُحزَّم** داخل APK/IPA.

## `quran-uthmani.xml`

- **المصدر:** Tanzil Quran Text (Uthmani, Version 1.1) — Tanzil Project.
- **الترخيص:** Creative Commons Attribution 3.0 (انظر رأس الملف نفسه).
- **الحجم:** ~1.47MB.

### لماذا أُخرج من الحزمة؟

كان الملف موضوعاً في `assets/data/` (المُعلَن كاملاً في `pubspec.yaml`)، فيُشحن مع
التطبيق دون أي استخدام فعلي:

- لا يوجد أي مرجع له في `lib/` (لا مسار ولا `rootBundle`).
- المشروع لا يعتمد أي مكتبة تحليل XML.
- نصوص المصحف في التطبيق تأتي من `qcf_quran` (العرض) ومن واجهة Quran.com
  (`text_uthmani` / `text_uthmani_simple`) ثم تُخزَّن في Drift.

أي أن الملف مرجع/نسخة احتياطية للنص فقط، وليس تبعية تشغيلية.

### الإسناد (Attribution)

بما أن بيانات النص القرآني مشتقة أصلاً من Tanzil، يجب أن تبقى الإشارة إلى
Tanzil Project قائمة في شاشة «عن التطبيق» أو في ملف الإسناد، حتى لو لم يُشحن
هذا الملف. حذف الملف من الحزمة لا يُسقط التزام الترخيص.

### الاستخدام المحتمل

إذا احتجت لاحقاً إلى بحث نصي محلي كامل، فالأفضل تحويله إلى قاعدة بيانات مسبقة
البناء (Drift / SQLite FTS) بدل قراءة XML وقت التشغيل.
